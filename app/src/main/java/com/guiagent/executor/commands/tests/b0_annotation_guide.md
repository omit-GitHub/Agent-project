# B0 最小标注集选取指南

## 目标

从 63 张截图中选取 30 张代表性截图，覆盖以下场景：

## 场景分类

### 1. App 覆盖 (每类 4-5 张)
- [ ] 爱奇艺 (iQiyi)
- [ ] 腾讯视频 (Tencent)
- [ ] 夸克网盘 (Quark)

### 2. 播放器状态 (每类 3-4 张)
- [ ] 控制条可见
- [ ] 控制条隐藏
- [ ] 倍速面板打开
- [ ] 清晰度面板打开

### 3. 页面类型 (每类 3-4 张)
- [ ] 播放器页面
- [ ] 详情页
- [ ] 搜索页
- [ ] 列表/网格页
- [ ] 菜单浮层

### 4. 元素类型 (确保覆盖)
- [ ] 纯图标（无文字）
- [ ] 文字按钮
- [ ] 卡片
- [ ] 菜单项
- [ ] 自绘控件（无 accessibility 节点）

## 标注格式

```json
{
  "screenshot": "screen_XXX.png",
  "annotations": [
    {
      "bbox": [x1, y1, x2, y2],
      "kind": "icon|text_button|card|menu_item|slider",
      "high_risk": false,
      "label": "可选标签"
    }
  ]
}
```

## 高风险操作标记

以下操作标记为 `high_risk: true`:
- 支付/购买按钮
- 删除/卸载按钮
- 退出登录按钮
- 发送/提交按钮

## 选取策略

1. 从 manifest.jsonl 中按 page_type 分组
2. 每组随机抽取 3-5 张
3. 优先选择包含多种元素类型的截图
4. 确保覆盖所有 App 和场景
