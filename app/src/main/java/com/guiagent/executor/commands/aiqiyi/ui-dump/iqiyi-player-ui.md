|---|---|---|---|

## 五、手势支持实测

| 手势 | 区域 | 结果 |
|---|---|---|
| 右侧垂直滑动 (x=75%, 700ms) | 音量 | ✅ **有效**，每次滑动改变系统 STREAM_MUSIC 音量 |
| 左侧垂直滑动 (x=25%, 700ms) | 亮度 | ❌ **无效**，系统亮度 settings 未变 |

> 结论：爱奇艺中屏版的播放页**不支持左侧滑调亮度**。
> 亮度控制需要走其他途径（系统 API 或放弃该功能）。

## 六、唤出控制条

控制条默认隐藏，需要先唤出：
- `tap` 屏幕中心 (640, 400) → 约 0.8~1s 后控制条完全显示
- 控制条约 5~8s 后自动隐藏
- 操作窗口：tap 后 ~1s 内完成点击
